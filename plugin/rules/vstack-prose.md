Every text you write follows `skill://unslop` and `skill://simple-english` in Plain mode. That covers chat, `ask` text, pages, PR and commit text, tracker text, and agent-facing text. Read both skills before your first text in a session. Agent-facing text (AGENTS.md, skills, agents, rules, and subagent briefs and results) also follows `skill://writing-for-agents`.

These choices override the skills:

- The Document register applies to every text, chat included. Use lists, headings, and tables only when they carry structure.
- Never use bold. Bold lead-ins are bold too.
- Where unslop and simple-english differ, simple-english wins.
- A short definition in parentheses is allowed.
- Never write may, might, could, should, or would.
- In agent-facing text, a leading word from writing-for-agents stays with no definition.
