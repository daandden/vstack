# Selected Emil skills govern animation guidance

Vstack restores good-css's hand-offs to the selected skills from the [UI upstream](../../GLOSSARY.md#sources), `emilkowalski/skills`. Those skills take precedence over good-css for animation guidance. We chose this over good-css-only precedence because the selected skills contribute motion and interaction judgment beyond CSS declarations.

When Emil's own skills disagree, reconcile their guidance using browser-specific behavior and observed evidence. Do not turn a broad rule such as transform-and-opacity-only animation into a prohibition without considering supported browser behavior. Preserve blocking motion-review verdicts, but justify them with the applicable rule and evidence rather than an unqualified blanket rule.

This decision does not replace good-css for other CSS work or create another user-started flow. Existing vstack skills retain execution, review, verification, and evidence ownership. The [principle-only implementation selection policy](0039-main-agent-tools-pick-addons-from-gathered-intent.md) remains unchanged; selected guidance must be reachable through relevant existing skill references.
