Settled · ADR 0004

Inline means no subagents

"On inline, the agent at that step does the work itself." A single subagent is not Fan-out and always runs as written.

Q1how: Simple/Complex → Fan-out block

pstack how has two paths: Simple means one explainer explores and explains in one pass (Step 2b). Complex means 2–4 explorers run in parallel and then one explainer combines their findings (Steps 2a, 3). "When in doubt, take the simple path." In vstack the judge now decides about parallelism, and its inline branch can't spawn anything. The question is where the judge sits and what inline does.

Option A (recommended). The gate only runs when there are 2+ angles, since one explainer isn't a Fan-out. Green = the how agent works itself.

Q4why's evidence sources in omp

Before spawning investigators, list the available MCPs from the Cursor environment. Use the available-tools map when present. Otherwise inspect the mcps/ directory Cursor exposes for enabled MCP servers. — pstack why, line 64

What omp actually exposes (per mcp-runtime-lifecycle.md): MCP tools are registered as mcp__<server>_<tool>. They appear either as top-level tools or under xd://, and the system prompt lists them along with each server's instructions. A subagent uses the parent's MCP manager, so investigators see the same tools. omp has no mcps/ directory.
