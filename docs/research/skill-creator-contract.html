(a) give recipients a copy of the Licensemet: license.txt ships

R2Round 2: how the headless runs behave

These follow from Q1, which chose headless omp -p runs. Fact: the parent's live model and thinking level come from the last model_change.model and thinking_level_change.thinkingLevel in $PI_SESSION_FILE (checked: anthropic/claude-opus-5-5, high).

Facts: task.maxConcurrency defaults to 32 and bounds only subagents, not processes. omp memory is per project (cwd) and is off by default, and --config loads a config overlay. [INFERENCE] --no-extensions should drop the vstack principle-injection extension; this can't be probed until vstack is linked. Probed: a candidate copy under a temp .omp/skills/ does not shadow the real skill, because both get listed (Q4 probe). So a candidate description has to be a temporary edit of the skill's own file.
