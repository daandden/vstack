## vstack

### Issue tracker

Issues and specs live in GitHub Issues at `daandden/vstack`. Before tracker operations, read `docs/vstack/issue-tracker.md`.

### Code host

PRs live on GitHub at `daandden/vstack`, through the `gh` CLI. Before PR operations, read `docs/vstack/code-host.md`.

### CI service

Builds and checks run on GitHub Actions through the `gh` CLI. Before reading build logs, rerunning builds, or storing CI secrets and variables, read `docs/vstack/ci.md`. Required PR checks stay with the Code host.

### Triage labels

Use the five default triage labels. Before triaging issues, read `docs/vstack/triage-labels.md`.

### Domain docs

This repo uses a single-context layout. Before exploring the codebase, read `docs/vstack/domain.md`.
