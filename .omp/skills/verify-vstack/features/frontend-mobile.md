## Gotchas

- Mobile-native retains an Upstream name but supplies mobile-web guidance. This recipe proves neither Expo animation nor Swift development.
- Device emulation and synthetic insets prove only the exercised browser scenarios. Physical touch feel, actual notch geometry, software keyboards, mobile Safari focus zoom, status bars, and installed-PWA behavior require their own real-platform evidence.
- Viewport and safe-area checks are both required. A successful narrow layout does not prove safe-area handling.
- A loaded pointer or scripted echo does not establish applied guidance. Retain actual native tool activity, worker edits, and observed frontend behavior.
- Hardware or another engine that is unavailable stays unavailable. Do not replace its missing evidence with an inferred pass.
